# 03. 로그라이크 요소

> 매 런이 다르게 흘러가게 만드는 것: 무작위 선택지, 쌓여가는 빌드, 한 번 지면 처음부터.

## 런 구조 ✅
```
런 시작
 └ 고개 1 ~ 8
     ├ 판 1      목표 ×1
     ├ 장터
     ├ 판 2      목표 ×1.5
     ├ 장터
     ├ 요괴 판   목표 ×2 + 특수 규칙
     └ 요괴 유품 → 장터
 └ 고개 8의 요괴는 이무기 (최종, 목표 ×3) → 엔딩 → 끝없는 모드 선택 (⏳)
```
- 판을 시작하기 전에 목표 점수와 요괴 규칙을 미리 보여준다.
- 판 하나라도 실패하면 런 종료 → 공덕 정산 → [06. 인크리멘탈 요소](06-incremental.md)
- 블록을 놓을 때마다 자동 저장. 앱을 꺼도 이어서 할 수 있다 (v0.3).

## 매 런이 달라지는 이유
| 무작위 요소 | 무엇이 바뀌나 | 단계 |
|---|---|---|
| 블록 뽑기 | 가방에서 나오는 순서와 방향 | ✅ |
| 장터 진열 | 부적, 소모품, 블록 팩 구성 | ✅ |
| 요괴 | 고개 1~7에 나오는 요괴 | ✅ |
| 보너스 칸 | 판마다 0~2개, 위치와 종류 | ✅ |
| 바위 | 위치 (개수는 고개마다 정해짐) | ✅ |
| 확률 부적 | 🥢 윷가락, 🪄 도깨비 방망이 등 | ✅ |

## 장터 ✅
판이 끝날 때마다 열린다.

| 진열 | 개수 | 내용 |
|---|---|---|
| 부적 | 2 | 등급 확률 일반 70% / 고급 25% / 희귀 5% |
| 소모품 | 2 | 비전서, 망치, 부채 등 |
| 블록 팩 | 1 | 블록 3개 중 1개를 골라 가방에 추가 (블록 강화가 들어가면 20% 확률로 강화된 블록 ⏳) |
| 블록 빼기 | 장터당 1번 | 가방에서 블록 1개 제거 (가방은 최소 10개) |
| 리롤 | 제한 없음 | 부적·소모품 진열을 새로 뽑음. 누를수록 비싸짐 |

- 부적은 장터에서 언제든 팔 수 있다 (구매가의 절반).
- 가격은 [07. 경제](07-economy.md)

## 소모품
최대 2개까지 들고 다니며, 판 중이나 장터에서 쓴다.

| 소모품 | 효과 | 단계 |
|---|---|---|
| 📖 비전서 (족보별 5종) | 해당 족보 레벨 +1 | ✅ |
| 🔨 망치 | 판의 칸 1개를 부숨 (바위 포함) | ✅ |
| 🌬️ 부채 | 손에 든 블록 1개를 90° 회전 | ✅ |
| 🧹 빗자루 | 가로 또는 세로 1줄을 비움 (점수 없음) | ⏳ |
| 🔖 도장 (5종) | 가방의 블록 1개를 강화 (금·수정·불꽃·유리·행운) | ⏳ |
| 🖌️ 먹 | 가방의 블록 1개를 복제 | ⏳ |
| ⌛ 모래시계 | 마지막에 놓은 블록 되돌리기 | ⏳ |

## 요괴 유품 ✅
- 요괴 판을 클리어하면 유품 3개 중 1개를 무료로 고른다 (고급 이상 부적 2개 + 비전서 1개).
- 고개 4부터는 유품에 20% 확률로 전설 부적이 섞인다 ⏳

## 판 건너뛰기 ⏳
- 판 1·판 2를 건너뛰고 대신 보상(무료 블록 팩, 다음 장터 할인 등)을 받는다.

## 가방 종류 (런 시작 때 고름)
| 가방 | 특징 | 해금 조건 | 단계 |
|---|---|---|---|
| 기본 가방 | 고르게 섞인 18개 | 처음부터 | ✅ |
| 막대 가방 | 막대 블록 위주, 🌀 바람개비를 들고 시작 | 고개 3 클리어 | ⏳ |
| 네모 가방 | ㅁ·큰ㅁ 위주, 대청소가 쉬움 | 대청소 10번 | ⏳ |
| 혼돈 가방 | 모든 블록이 무작위로 강화됨, 부적 칸 −1 | 엔딩 1번 | ⏳ |

## 열린 질문
- ❓ 런 길이: 8고개(목표 40~50분) vs 6고개(약 30분) → **8고개 추천**. 중간 저장이 되니 나눠서 하면 된다.
- ❓ 판 건너뛰기를 첫 버전에 넣을지 → **나중에 추천**
