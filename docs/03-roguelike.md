# 03. 로그라이크 요소

> 매 런이 다르게 흘러가게 만드는 것: 무작위 선택지, 쌓여가는 빌드, 한 번 지면 처음부터.

## 런 구조 ✅
```
런 시작
 └ 고개 1 ~ 8
     ├ 판 1      목표 ×1
     ├ 장터
     ├ 판 2      목표 ×1.5
     ├ 장터
     ├ 요괴 판   목표 ×2 + 특수 규칙
     └ 요괴 유품 → 장터
 └ 고개 8의 요괴는 이무기 (최종, 목표 ×3) → 엔딩으로 끝내기 / 끝없는 모드로 계속 ✅
```
- 판을 시작하기 전에 목표 점수와 요괴 규칙을 미리 보여준다.
- 판 하나라도 실패하면 런 종료 → 공덕 정산 → [06. 인크리멘탈 요소](06-incremental.md)
- 블록을 놓을 때마다 자동 저장. 앱을 꺼도 이어서 할 수 있다 (v0.3).
- 새 런은 런 준비 화면에서 가방과 난이도 단계를 고르고 시작한다 (v1.0).

## 매 런이 달라지는 이유
| 무작위 요소 | 무엇이 바뀌나 | 단계 |
|---|---|---|
| 블록 뽑기 | 가방에서 나오는 순서와 방향 | ✅ |
| 장터 진열 | 부적, 소모품, 블록 팩 구성 | ✅ |
| 요괴 | 고개 1~7에 나오는 요괴 | ✅ |
| 보너스 칸 | 판마다 0~2개, 위치와 종류 | ✅ |
| 바위 | 위치 (개수는 고개마다 정해짐) | ✅ |
| 확률 부적·강화 | 🥢 윷가락, 🪄 도깨비 방망이, 행운·유리 블록 | ✅ |
| 끝없는 모드 요괴 | 고개 9부터 고개마다 새로 뽑음 (8의 배수 고개는 이무기) | ✅ |

## 장터 ✅
판이 끝날 때마다 열린다.

| 진열 | 개수 | 내용 |
|---|---|---|
| 부적 | 2 | 등급 확률 일반 67% / 고급 24% / 희귀 5% / 저주 4% (저주는 고개 3을 본 뒤부터, 팔 수 없음) |
| 소모품 | 2 | 비전서 38%, 망치 14%, 도장 14%, 부채 11%, 빗자루 9%, 먹 8%, 모래시계 6% |
| 블록 팩 | 1 | 블록 3개 중 1개를 골라 가방에 추가. 블록마다 20% 확률로 강화돼 있다. ㄷ·더하기도 여기서만 나온다 |
| 블록 빼기 | 장터당 1번 | 가방에서 블록 1개 제거 (가방은 최소 10개) |
| 리롤 | 제한 없음 | 부적·소모품 진열을 새로 뽑음. 누를수록 비싸짐 (✂️ 엿장수 가위가 있으면 장터마다 1번 무료) |

- 부적은 장터에서 언제든 팔 수 있다 (구매가의 절반).
- 새 런은 해금한 부적만 진열된다. 오늘의 판·코드 도전은 해금과 상관없이 전부 나온다 (누구나 같은 진열) → [06](06-incremental.md)
- 가격은 [07. 경제](07-economy.md)

## 소모품
최대 2개까지 들고 다닌다 (수련 "소매"로 +1). 망치·부채·빗자루·모래시계는 판 진행 중에, 도장·먹은 장터에서, 비전서는 아무 때나 쓴다. 부채·모래시계는 누르면 바로 쓰이고, 망치·빗자루는 누른 뒤 칸을 고른다.

| 소모품 | 효과 | 단계 |
|---|---|---|
| 📖 비전서 (족보별 5종) | 해당 족보 레벨 +1 | ✅ |
| 🔨 망치 | 고른 칸을 가운데로 3×3 칸을 부숨 (바위·방해 칸 포함, 물은 그대로, 점수 없음) | ✅ |
| 🌬️ 부채 | 이번 판 동안 손의 블록을 눌러서 90°씩 돌릴 수 있음 (🌀 바람개비를 한 판 빌리는 셈) | ✅ |
| 🧹 빗자루 | 가로 또는 세로 1줄을 지우고 "한 줄" 점수를 받음. 부적·연속·강화 칸·보너스 칸이 적용되고, 바위·방해 칸도 지운다 (물은 그대로). 놓은 블록이 없으므로 블록 모양·가장자리 조건 부적은 안 붙는다 | ✅ |
| 🔖 도장 (5종) | 가방의 블록 2개를 강화 (금·수정·불꽃·유리·행운). 이미 강화된 블록이면 바뀐다 | ✅ |
| 🖌️ 먹 | 가방의 블록 1개를 강화까지 똑같이 하나 더 | ✅ |
| ⌛ 모래시계 | 이번 판 핸드 +1 (일찍 깨면 남은 핸드 보상도 그만큼) | ✅ |

- ↩ 되돌리기는 소모품이 아니라 판마다 1번 무료: 마지막에 놓은 블록을 되돌린다 (그 블록으로 생긴 점수·골드·클리어도 함께). 놓은 뒤 버리기·소모품 등 다른 걸 했으면 못 쓴다. 상태 줄 오른쪽 버튼.
- v1.1 조정: 봇 400판에서 런이 끝난 이유가 모두 점수 부족이었고 막혀서 끝난 런은 0이었다. 막힘 구제용 소모품은 살 이유가 없어서, 점수·핸드에 직접 도움이 되게 바꾸고 되돌리기는 무료 기능으로 뺐다 → [08](08-difficulty.md)

## 요괴 유품 ✅
- 요괴 판을 클리어하면 유품 3개 중 1개를 무료로 고른다 (고급 이상 부적 2개 + 비전서 1개).
- 고개 4부터는 유품에 20% 확률로 전설 부적이 섞인다 (부적 2개 중 1개가 전설) ✅

## 판 건너뛰기 ✅ (v1.1)
- 판 1·판 2의 미리보기에서 건너뛰면 그 판의 보상과 바로 다음 장터를 건너뛰고, 대신 아래 중 하나를 받는다 (판마다 정해져 있어서 미리보기에 보인다).
- 결과 네모는 ⬜. 미리보기 동안 바꾼 부적 순서·비전서는 그대로 들고 간다.

| 보상 | 효과 |
|---|---|
| 💰 노잣돈 | 바로 +$10 |
| 🎁 공짜 블록 팩 | 다음 장터의 블록 팩이 공짜 |
| 🏷️ 반값 부적 | 다음 장터의 부적이 반값 (내림, 최소 $1) |
| 🔄 공짜 리롤 | 다음 장터에서 리롤 3번 공짜 |
| 📖 족보 공부 | 무작위 족보 3개 레벨 +1 |

- v1.1 조정: 처음 값($6·리롤 2번·족보 2개)은 봇이 판 1을 늘 건너뛰면 깬 판이 크게 줄어서 올렸다 → [08](08-difficulty.md)

## 가방 종류 (런 시작 때 고름) ✅
| 가방 | 특징 | 해금 조건 | 단계 |
|---|---|---|---|
| 기본 가방 | 고르게 섞인 18개 | 처음부터 | ✅ |
| 막대 가방 | 막대 블록 11개 위주 18개, 🌀 바람개비를 들고 시작 | 고개 3 클리어 (고개 4 도달) | ✅ |
| 네모 가방 | ㅁ 4·큰ㅁ 2·직사각 2 포함 18개, 대청소가 쉬움 | 대청소 누적 10번 | ✅ |
| 혼돈 가방 | 기본 가방 구성인데 모든 블록이 무작위로 강화됨 (같은 코드면 같은 강화), 부적 칸 −1 | 엔딩 1번 | ✅ |

- 오늘의 판·코드 도전은 늘 기본 가방으로 한다.

## 열린 질문
- ❓ 런 길이: 8고개(목표 40~50분) vs 6고개(약 30분) → **8고개 추천**. 중간 저장이 되니 나눠서 하면 된다.
- ❓ 판 건너뛰기를 첫 버전에 넣을지 → v1.1에 넣음. 보상은 봇 비교로 한 번 올렸고, 사람이 해보고 다시 조정
