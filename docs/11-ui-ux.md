# 11. 화면 · 조작

> 세로 화면, 한 손 엄지. 움직이는 연출은 짧은 CSS 효과만.

## 플레이 화면 (위 → 아래)
| 영역 | 내용 | 높이 |
|---|---|---|
| 상단 정보 | 고개·판, 목표 / 현재 점수, 골드 | 약 10% |
| 상태 줄 | 남은 핸드, 버리기, 연속 | 약 5% |
| 부적 줄 | 부적 5칸 (탭하면 설명과 ← → 순서 이동 버튼. 끌어서 옮기기는 ⏳) | 약 10% |
| 판 | 8×8 정사각형, 화면 폭의 92% | 약 45% |
| 점수 줄 | 이번 클리어의 칩 × 배수 | 약 6% |
| 손 | 블록 3개 (🎁 덤이면 4개), 🎒 보따리가 있으면 맨 오른쪽에 보관함. 칸이 늘면 블록을 조금 작게 | 약 16% |
| 하단 버튼 | 소모품 2칸, 버리기, 가방 보기 | 약 8% |

- 작은 폰(아이폰 SE, 폭 375px)에서도 칸 하나가 약 43px.

## 드래그 조작 ✅
- 손의 블록을 누르면 판 크기로 커지면서 **손가락보다 약 2칸 위**에 떠서 따라온다. 손가락에 가려지지 않게 하기 위해서다.
- 판 위에 놓일 자리를 미리 표시한다: 놓을 수 있으면 연한 색, 못 놓으면 빨간 테두리.
- 이 자리에 놓으면 지워질 줄을 미리 반짝여서 보여준다.
- 손을 떼면 가장 가까운 칸에 맞춰 놓인다. 못 놓는 곳이면 손으로 돌아간다.
- 마우스와 터치를 같이 처리하도록 Pointer Events를 쓴다.
- 손의 블록을 빈 보관함에 끌어다 놓으면 보관, 보관함의 블록은 판으로 끌어서 꺼낸다 (v1.0).
- 🐅 장산범이 가린 블록(?)은 누르는 순간 드러난다.
- 🔨 망치는 칸 하나, 🧹 빗자루는 점수 줄에 뜬 [가로줄|세로줄]을 고른 뒤 칸을 누른다.

## 연출 (짧게, 끄거나 빠르게 할 수 있게)
| 순간 | 연출 |
|---|---|
| 블록 놓기 | 살짝 눌리는 효과 (100ms) |
| 줄 지우기 | 칸이 반짝이고 사라짐 (200ms) |
| 점수 계산 | 칩 → 배수 → 결과 숫자가 차례로 올라감 (발라트로식) |
| 부적 발동 | 해당 부적이 흔들리며 "+4 배수" 같은 글자 |
| 대청소 | 판 전체가 번쩍이고 큰 글씨 |
| 연속 | 연속 숫자가 커지며 색이 바뀜 |

- 설정: 연출 속도 ×1 / ×2 / ×4
- 진동: 안드로이드만 지원 (아이폰 사파리는 진동 API가 없음)
- 애니메이션은 transform, opacity만 써서 끊김을 막는다

## 정보 보기
- 부적, 소모품, 요괴를 탭하면 설명 말풍선 ✅
- 가방 보기: 남은 블록과 전체 구성. 같은 모양이라도 강화가 다르면 따로 묶고, 가방에 있는 강화의 뜻을 아래에 보여준다 ✅
- 강화 블록: 칸 테두리 색 + 가운데 표시(`$ ✦ ▲ ◇ ☘`). 손·판·가방 어디서나 같은 모양 ✅
- 점수 계산 내역: 마지막 클리어의 계산 과정을 단계별로 펼쳐보기 ⏳

## 처음 하는 사람 ✅
- 첫 런의 고개 1에서 3단계 안내: ① 블록을 끌어다 놓기 ② 줄을 채우면 지워짐 ③ 목표 점수를 넘기면 클리어
- 장터 첫 방문 때 부적 설명 1번

## 접근성
- 색만으로 구분하지 않는다. 보너스 칸, 바위, 강화 블록은 아이콘과 무늬를 같이 쓴다.
- 글씨는 최소 14px, 중요한 숫자는 크게.
- 왼손 모드 (하단 버튼 좌우 반전) ⏳

## 저장과 이어하기 ✅ (v0.3)
- 블록을 놓을 때마다 자동 저장. 탭이 닫혀도 그 자리에서 이어서 한다.
- 세이브 코드 내보내기/가져오기 ⏳ (기기 이동, 아이폰 저장 데이터 삭제 대비)

- ❓ 칸 크기 약 43px이 엄지로 충분한지 → v0.1에서 실제 폰으로 확인
