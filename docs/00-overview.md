# 블록 도사 (가제) 개요

> 블록블라스트처럼 8×8 판에 블록을 놓아 줄을 지우는 퍼즐 위에, 발라트로식 로그라이크와 인크리멘탈 성장을 얹은 모바일 웹 게임.
> 판매용이 아니라 친구들과 기록 겨루기, 혼자 엔딩 보기용.

## 한 줄 소개
판에 블록을 놓아 줄을 지우고, 부적을 모아 점수를 키워서 요괴가 지키는 8개의 고개를 넘는다.

## 레퍼런스
| 게임 | 가져오는 것 |
|---|---|
| 블록블라스트, 1010! | 8×8 판, 블록 3개씩 받기, 가로·세로 줄 지우기 |
| 발라트로 | 목표 점수 판, 칩 × 배수, 상점과 조커(→ 부적), 족보 레벨업, 보스 규칙 |
| 인크리멘탈 게임 전반 | 영구 강화, 해금, 숫자가 끝없이 커지는 후반 |

## 디자인 원칙
1. **움직이는 건 최소로**: 턴제. 실시간 요소와 물리엔진 없음. 연출은 짧은 CSS 효과만.
2. **규칙은 3초 안에**: "블록 놓고 줄 지우기"만 알면 시작할 수 있다. 나머지는 하면서 배운다.
3. **한 손, 세로 화면**: 자주 누르는 건 화면 아래쪽에 둔다.
4. **숫자는 커져야 한다**: 점수 계산 과정(칩 × 배수)을 보여주고, 만·억·조 같은 한국식 단위로 커지는 맛을 살린다.
5. **같은 운, 다른 선택**: 시드가 같으면 같은 블록과 같은 장터가 나온다. 친구와 판단력으로 겨룬다.
6. **끝이 있다**: 8고개를 넘으면 엔딩. 그 뒤는 끝없는 모드.

## 핵심 루프
```
[판]   블록 3개 받기 → 판에 놓기 → 줄 지우기 → 칩 × 배수 점수 → 목표 점수를 넘기면 클리어
[런]   판 1 → 장터 → 판 2 → 장터 → 요괴 판 → 장터 → 다음 고개 … 고개 8 → 엔딩 (→ 끝없는 모드)
[메타] 런 종료 → 공덕 획득 → 수련(영구 강화)·해금 → 다음 런은 조금 더 멀리
```

## 런 한눈에 보기
- 런은 8개의 **고개**로 되어 있고, 고개마다 **판 1 → 판 2 → 요괴 판**을 깬다.
- 판마다 **핸드 5번**(핸드 = 블록 3개)이 주어지고, 그 안에 **목표 점수**를 넘기면 클리어. 못 넘기면 런이 끝난다.
- 판 사이 **장터**에서 부적, 소모품, 블록을 사서 빌드를 만든다.
- 런이 끝나면 **공덕**을 받아 **수련**(영구 강화)에 쓴다.

## 테마 (가안)
떠돌이 도사가 요괴가 막고 있는 8개의 고개를 넘는다. 판은 요괴가 어지럽힌 결계판이고, 줄을 채우면 결계가 완성되어 지워진다.
- 그림은 이모지, 단색 블록, 한지 느낌 배경(CSS)으로 해결한다.
- 테마 이름은 데이터에만 두기 때문에, 테마를 바꿔도 규칙은 그대로다.

## 용어
| 용어 | 뜻 | 발라트로 대응 |
|---|---|---|
| 런 | 한 번의 도전. 실패하면 처음부터 | Run |
| 고개 | 판 3개 묶음. 총 8고개 | Ante |
| 판 | 목표 점수를 넘겨야 하는 한 판 (판 1 / 판 2 / 요괴 판) | Blind |
| 핸드 | 한 번에 받는 블록 3개. 3개를 다 놓아야 다음 핸드 | Hand |
| 버리기 | 손의 블록 1개를 버리고 새로 뽑기 | Discard |
| 가방 | 내 블록 덱 | Deck |
| 족보 | 한 줄, 두 줄, 십자, 세 줄, 네 줄+ | Poker hand |
| 칩 · 배수 | 점수 = 칩 × 배수 | Chips · Mult |
| 연속 | 클리어가 이어진 횟수 | — |
| 대청소 | 줄을 지운 뒤 판이 완전히 빈 상태 | — |
| 강화 | 가방 블록에 붙는 효과 (금·수정·불꽃·유리·행운) | Enhancement |
| 부적 | 규칙을 비트는 장착 아이템 | Joker |
| 소모품 · 비전서 | 1회용 아이템 · 족보 레벨업 아이템 | Tarot · Planet |
| 장터 | 판 사이 상점 | Shop |
| 요괴 | 특수 규칙이 붙은 보스 판 | Boss Blind |
| 공덕 · 수련 | 메타 재화 · 영구 강화 | — |
| 난이도 단계 | 엔딩 후 열리는 상위 난이도 | Stake |
