# 06. 인크리멘탈 요소

> 두 층으로 나뉜다. **런 안**에서 숫자가 폭발하는 맛, **런 밖**에서 영구히 강해지는 맛.

## 1. 런 안: 숫자가 커지는 구조 ✅
| 장치 | 커지는 방식 | 예 |
|---|---|---|
| 족보 레벨업 | 덧셈. 같은 족보를 계속 키움 | 비전서로 두 줄 Lv.5 |
| 성장형 부적 | 런 동안 쌓임 | 🪵 나이테, 🎋 대나무 |
| 배수 × 겹치기 | 곱셈. ×2, ×3이 서로 곱해짐 | 🐯 호랑이 부적 + 📃 백지 부적 |
| 목표 점수 | 고개마다 약 2.5배 | [08. 난이도](08-difficulty.md) |

- 고개 1~4는 덧셈(칩, 배수 +)만으로도 넘을 수 있다.
- 고개 5부터는 곱셈(배수 ×, 성장형)이 없으면 막히게 목표를 잡는다 → "빌드가 완성되는 순간"이 생긴다.

## 2. 런 밖: 공덕과 수련 ✅ (v0.3)
### 공덕 얻기
| 항목 | 공덕 |
|---|---|
| 도달한 고개 | 고개당 10 |
| 처치한 요괴 | 1마리당 5 |
| 엔딩 | +50 |
| 처음 달성 (고개 2부터 첫 도달, 첫 엔딩) | 1번만 20 |

- 예: 고개 3에서 실패, 요괴 2마리 처치 → 30 + 10 = 40
- 엔딩: 80 + 40 + 50 = 170 (처음 달성 보너스 제외)
- 끝없는 모드로 넘어가면 엔딩을 본 것으로 친다. 그 뒤로도 고개당 10, 요괴당 5, 처음 도달한 고개 20씩 계속 쌓인다
- 오늘의 판 완주(끝판)는 엔딩이 아니다
- 공덕은 런이 끝날 때(실패·엔딩) 받는다. 진행 중인 런을 두고 새 런을 시작하면 그 런은 공덕 없이 사라진다.
- 수련은 다음 런부터 적용된다. 진행 중인 런은 시작할 때의 수련 그대로 간다.

### 수련 (영구 강화)
| 수련 | 효과 | 단계별 비용 |
|---|---|---|
| 넉넉한 전대 | 시작 골드 +$2 | 30 / 60 / 120 |
| 저축 | 이자 상한 +$2 | 60 / 150 |
| 소매 | 소모품 칸 +1 | 80 |
| 손놀림 | 판마다 버리기 +1 | 100 / 250 |
| 첫 인연 | 런 시작 때 일반 부적 3개 중 1개를 골라서 시작 | 100 |
| 기사회생 | 런당 1번, 막혀서 판이 끝나려 할 때 가장 많이 찬 2줄을 비움 | 120 |
| 단골 | 장터 부적 진열 +1 | 150 |
| 부적 주머니 | 부적 칸 +1 | 200 |
| 수련된 손 | 런 시작 때 모든 족보 레벨 +1 | 250 |
| 끈기 | 판마다 핸드 +1 | 300 |

- 전부 사려면 약 1,970 공덕. 엔딩만 본다면 약 12번, 고개 3 탈락만 반복하면 약 50번.
- 큰 강화(핸드, 부적 칸)는 비싸게 둬서 "반복만 하면 깨지는 게임"이 되지 않게 한다.

## 3. 해금 ✅ (v1.0)
런을 시작할 때의 기록(최고 고개, 엔딩 수, 대청소 누적, 런 수)으로 판단한다.

| 해금 대상 | 조건 |
|---|---|
| 🐸 두꺼비 / ⛄ 눈사람 / 🪄 도깨비 방망이 | 대청소 누적 3번 / 대청소 누적 10번 / 고개 5 도달 |
| 막대 가방 / 네모 가방 / 혼돈 가방 | 고개 4 도달 / 대청소 누적 10번 / 엔딩 1번 |
| 난이도 단계 | 바로 아래 단계로 엔딩 (새 런만, 코드 도전은 안 침) |
| 끝없는 모드 | 따로 해금 없음. 고개 8 이무기를 깨면 그 자리에서 고를 수 있다 |

- 오늘의 판·코드 도전은 누구나 같은 조건: 수련 없이, 기본 가방·1단계로, 부적은 해금과 상관없이 전부 나온다.

## 4. 도감과 기록
- 기록 ✅: 처음 화면에 최고 고개, 엔딩, 런 수, 최고 한 방, 대청소 누적, 깬 난이도
- 도감 ✅ (v1.1): 처음 화면의 "도감". 런이 끝나면 그 런에서 얻은 부적, 만난 요괴·방해 칸, 가방에 있던 블록·강화가 채워진다. 수집률 %와 칸마다 설명 (못 만난 것은 ???)

## 5. 끝없는 모드 ✅ (v1.0)
- 고개 8 이무기를 깨면 "여기서 마치기"와 "끝없는 모드로 계속" 중에서 고른다. 계속하면 유품 → 장터 → 고개 9.
- 목표 점수가 훨씬 빠르게 커진다 → [08. 난이도](08-difficulty.md). 판에 실패하면 그때 런이 끝난다.
- 점수는 10³⁰⁰에서 멈춘다 (저장이 깨지지 않게).
- 도전 과제: 한 방에 **무량대수**(10⁶⁸) 찍기

## 숫자 표기 (한국식 단위) ✅
만(10⁴) · 억(10⁸) · 조(10¹²) · 경(10¹⁶) · 해(10²⁰) · 자(10²⁴) · 양(10²⁸) · 구(10³²) · 간(10³⁶) · 정(10⁴⁰) · 재(10⁴⁴) · 극(10⁴⁸) · 항하사(10⁵²) · 아승기(10⁵⁶) · 나유타(10⁶⁰) · 불가사의(10⁶⁴) · 무량대수(10⁶⁸)

- 1만 미만은 그대로 표시 (9,999)
- 예: 12,345 → 1.23만, 987,654,321 → 9.87억
- 반올림이 아니라 내림. 목표에 못 미친 점수(14,999)가 목표(1.5만)와 같아 보이지 않게 하기 위해서
- 무량대수를 넘으면 지수 표기 (1.2e70)
- 설정에서 한국식 / 지수 표기(1.23e8) 선택 ✅ (v1.1). 친구에게 보내는 결과 글은 늘 한국식

## 공정성
