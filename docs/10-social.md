# 10. 친구 요소

> 서버 없이 노는 게 기본. **같은 시드로 겨루고, 결과를 카톡에 붙여넣는다.**

## 오늘의 판 ✅ (v0.4)
| 항목 | 내용 |
|---|---|
| 시드 | 한국 시간 날짜로 생성. 모두 같은 블록 순서, 장터, 요괴, 바위 |
| 코스 | 고개 3까지 (9판) + **끝판** |
| 끝판 | 목표 없음. 핸드 5번 동안 낼 수 있는 최대 점수 |
| 세팅 | 기본 가방, 난이도 1단계, 수련·해금 효과 없음 |
| 순위 | 끝판 점수. 끝판 전에 탈락하면 도달한 판으로 비교 |
| 기록 | 첫 도전만 공식 기록, 그 뒤는 연습 |
| 길이 | 목표 15~20분 |

- 평소 판은 목표를 넘기는 순간 끝나서 점수 차이가 안 난다. 그래서 오늘의 판은 마지막에 점수를 끝까지 내는 끝판으로 실력 차를 낸다.
- 공식 기록은 "그날 처음 **시작한**" 도전이다. 중간에 새 런을 시작해서 버리면 그날 공식 기록은 없다 (미리 보고 다시 하기 방지). 진행 중인 공식 도전은 처음 화면에서 이어할 수 있다.
- 공식 기록과 그 결과 글은 처음 화면에 남아서, 나중에 다시 공유할 수 있다.
- 공덕도 받는다 (고개·요괴 기준). 끝판 완주는 엔딩이 아니라서 엔딩 공덕은 없다.

## 결과 공유 ✅ (v0.4)
결과 화면의 [공유]를 누르면 휴대폰 공유창(Web Share API)이 뜨고 카톡을 고르면 된다. 공유창이 안 되는 환경에선 클립보드에 복사한다.

```
🧱 블록 도사 · 오늘의 판 10/12
⛰️ 3고개 완주 · 끝판 23.4만
💥 최고 한 방 4.1만 (세 줄)
🟩🟩🟨 🟩🟩🟩 🟩🟨🟩
🏮🐦🥁🐯🪵
코드 D20261012
https://dosa.gaon.dev
```
- 네모 한 칸 = 판 하나: 🟩 핸드를 남기고 클리어, 🟨 마지막 핸드에 클리어, 🟥 실패
- 그다음 줄은 끝날 때 들고 있던 부적, 그다음은 같은 판에 도전할 수 있는 코드
- 마지막 줄은 게임 주소 (v1.1.2). 처음 보는 친구가 눌러서 바로 들어오고, 카톡에서는 링크 미리보기(그림·제목)가 붙는다. 결과 이미지에도 같이 그려진다
- 연습이면 제목에 `(연습)`, 수련을 쓴 새 런이면 코드 뒤에 `(수련 적용)`이 붙는다
- 끝없는 모드에서 멈추면 `⛰️ 여덟 고개 완주 → ♾️ 고개 11 · 판 2에서 멈춤`
- 공유 순서: 휴대폰 공유창 → 안 되면 클립보드 복사 → 그것도 안 되면 글을 길게 눌러 복사하도록 안내

## 시드 도전장 ✅ (v0.4)
- 모든 런에 6자리 시드 코드가 있다 (예: `K7Q2MX`). 오늘의 판은 `D` + 날짜 (예: `D20261012`).
- 처음 화면의 "코드로 도전"에 코드를 넣으면 같은 판으로 시작한다. 결과 글을 통째로 붙여넣어도 "코드 ○○○"를 찾아 읽는다.
- 코드 도전과 오늘의 판은 **수련 없이** 시작해서 조건이 같다. 지난 날짜의 오늘의 판 코드는 늘 연습이다.
- 기본이 아닌 가방·난이도로 한 런은 코드 뒤에 가방 글자와 단계가 붙는다: `K7Q2MX-H3` = 혼돈 가방·3단계 (가방 글자: 기본 G, 막대 M, 네모 N, 혼돈 H). 코드 도전은 수련 없이 그 가방·단계로 시작한다 (v1.1). 결과 글 제목 아래에도 `🌪️ 혼돈 가방 · 난이도 3 수행자`가 붙는다.
- 코드 도전으로 엔딩을 봐도 난이도 단계는 열리지 않는다 (새 런으로만).

## 공정성: 랜덤 분리
- 블록 뽑기, 장터, 바위·보너스 칸, 요괴, 확률 효과의 랜덤을 서로 따로 굴린다.
- 예: 장터에서 리롤을 많이 해도 블록 뽑기 순서는 바뀌지 않는다.
- 다만 가방을 다르게 다듬으면 그 뒤로 나오는 블록은 달라진다. 그게 실력 차이다.
- 구현 → [12. 기술 구성](12-tech.md)

## 카톡 공유 주의점
- 카톡에서 링크를 누르면 카톡 내장 브라우저로 열린다. 이 브라우저는 저장 공간이 따로라서 내 진행 상황이 안 보인다.
- 그래서 **같은 판 도전은 코드 붙여넣기**가 기본이다. 공유 텍스트에 시드 코드를 넣고, 게임 안에서 붙여넣는 방식.
- 링크는 처음 오는 사람을 위해 글 끝에 붙인다 (v1.1.2). 이미 하던 사람은 카톡 안에서 열면 기록이 안 보이므로, 평소 브라우저에서 "코드로 도전"에 코드를 넣으면 된다.

## 주간 도전 ✅ (v1.1)
- 월요일 0시(KST)에 바뀐다. 시드 = `W` + 그 주 월요일 날짜 (예: `W20261012`). 오늘의 판처럼 고개 3 + 끝판, 수련 없이.
- 주마다 특수 규칙 1개가 돌아가며 붙는다: 🥢 막대 잔치(점·막대 블록뿐), 🌪️ 혼돈의 주(혼돈 가방), ⏱️ 급한 길(핸드 −1, 버리기 +3), 👝 단출한 짐(부적 칸 3, 시작 골드 +$10), 🪨 돌밭(바위 +3), 🌿 방해 칸 잔치(고개 1부터 방해 칸), 🌀 바람 부는 날(바람개비를 들고 시작)
- 이번 주 첫 도전만 공식 기록. 처음 화면에 그 주의 공식 기록과 공유 글이 남는다. 지난주 코드는 연습.

## 결과 이미지 ✅ (v1.1)
- 런 결과에서 "🖼️ 이미지로": 결과 글을 1080×1080 카드(PNG)로 그린다. 공유창이 이미지를 받으면 공유, 아니면 이미지로 저장.
