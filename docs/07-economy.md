# 07. 경제

> 골드($)는 런 안에서만 쓰는 돈. **지금 쓸지, 모아서 이자를 받을지**가 매 장터의 고민.

## 수입 ✅
| 항목 | 금액 |
|---|---|
| 시작 골드 | $4 |
| 판 1 클리어 | $3 |
| 판 2 클리어 | $4 |
| 요괴 판 클리어 | $5 |
| 남은 핸드 | 아직 시작하지 않은 핸드 1개당 $1 |
| 이자 | 보유 골드 $5당 $1 (최대 $5) |
| 💎 보석 칸 | $3 |
| 부적·강화 | 👛 복주머니 $3, 🐸 두꺼비 $5, 금 블록 칸당 $1 (한 번에 최대 $8), 행운 블록 1/15 확률 $10 |

- 이자는 판 클리어 보상을 받기 직전의 보유 골드로 계산한다.
- 🔥 강철이 판은 판 중 골드도, 클리어 보상·이자도 없다.
- 난이도 "행자"(2단계)부터 판 1 클리어 보상 $0, "법사"(5단계)부터 이자 상한 $3 → [08](08-difficulty.md)

## 지출 ✅
| 항목 | 가격 |
|---|---|
| 부적 (일반 / 고급 / 희귀 / 저주) | $4 / $6 / $8 / $3 |
| 소모품, 비전서 | $3 (🖌️ 먹만 $2) |
| 블록 팩 | $4 |
| 블록 빼기 | $3 (장터당 1번) |
| 리롤 | $3부터 누를 때마다 +$1 (장터를 나가면 다시 $3). ✂️ 엿장수 가위는 장터마다 1번 무료 |
| 전설 부적 | 장터에 안 나옴 (요괴 유품 전용) |
| 부적 판매 | 구매가의 절반 (내림, 최소 $1) |

- 난이도 "진인"(7단계)부터 부적·소모품·블록 팩·블록 빼기가 +$1. 팔 때는 그대로.
- 판 건너뛰기 보상으로 받은 공짜 팩·반값·공짜 리롤은 바로 다음 장터에서만 쓴다 → [03](03-roguelike.md)

## 한 고개 수입 예시
남은 핸드 2개, 보유 골드 $25 이상을 유지한다고 가정:

| 판 | 기본 | 남은 핸드 | 이자 | 합 |
|---|---|---|---|---|
| 판 1 | $3 | $2 | $5 | $10 |
| 판 2 | $4 | $2 | $5 | $11 |
| 요괴 판 | $5 | $2 | $5 | $12 |

- 모아두면 고개당 약 $33, 다 써서 이자를 못 받으면 약 $18.
- 부적이 $4~8이라 고개당 부적 2~4개를 살 수 있는 흐름.

## 설계 의도
- **이자 vs 지금 강해지기**: $25를 모아두면 이자가 최대지만, 지금 부적을 안 사면 다음 판이 위험하다.
- **리롤 비용 상승**: 원하는 부적을 끝없이 찾을 수 없다. 나온 것으로 빌드를 짜게 만든다.
- **남은 핸드 보상**: 빨리 끝낼수록 돈이 된다. 점수를 크게 내는 빌드가 경제적으로도 이득.

## 열린 질문
- ❓ 이자 상한 $5 (보유 $25 기준)가 적당한지 → 해보고 조정
- ❓ 블록 빼기 가격: 고정 $3 vs 쓸수록 비싸짐 → **고정으로 시작 추천**
