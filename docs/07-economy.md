# 07. 경제

> 골드($)는 런 안에서만 쓰는 돈. **지금 쓸지, 모아서 이자를 받을지**가 매 장터의 고민.

## 수입 ✅
| 항목 | 금액 |
|---|---|
| 시작 골드 | $4 |
| 판 1 클리어 | $3 |
| 판 2 클리어 | $4 |
| 요괴 판 클리어 | $5 |
| 남은 핸드 | 아직 시작하지 않은 핸드 1개당 $1 |
| 이자 | 보유 골드 $5당 $1 (최대 $5) |
| 💎 보석 칸 | $3 |
| 부적·강화 | 👛 복주머니, 금 블록 등 |

- 이자는 판 클리어 보상을 받기 직전의 보유 골드로 계산한다.

## 지출 ✅
| 항목 | 가격 |
|---|---|
| 부적 (일반 / 고급 / 희귀) | $4 / $6 / $8 |
| 소모품, 비전서 | $3 |
| 블록 팩 | $4 |
| 블록 빼기 | $3 (장터당 1번) |
| 리롤 | $3부터 누를 때마다 +$1 (장터를 나가면 다시 $3) |
| 부적 판매 | 구매가의 절반 (내림, 최소 $1) |

## 한 고개 수입 예시
남은 핸드 2개, 보유 골드 $25 이상을 유지한다고 가정:

| 판 | 기본 | 남은 핸드 | 이자 | 합 |
|---|---|---|---|---|
| 판 1 | $3 | $2 | $5 | $10 |
| 판 2 | $4 | $2 | $5 | $11 |
| 요괴 판 | $5 | $2 | $5 | $12 |

- 모아두면 고개당 약 $33, 다 써서 이자를 못 받으면 약 $18.
- 부적이 $4~8이라 고개당 부적 2~4개를 살 수 있는 흐름.

## 설계 의도
- **이자 vs 지금 강해지기**: $25를 모아두면 이자가 최대지만, 지금 부적을 안 사면 다음 판이 위험하다.
- **리롤 비용 상승**: 원하는 부적을 끝없이 찾을 수 없다. 나온 것으로 빌드를 짜게 만든다.
- **남은 핸드 보상**: 빨리 끝낼수록 돈이 된다. 점수를 크게 내는 빌드가 경제적으로도 이득.

## 열린 질문
- ❓ 이자 상한 $5 (보유 $25 기준)가 적당한지 → 해보고 조정
- ❓ 블록 빼기 가격: 고정 $3 vs 쓸수록 비싸짐 → **고정으로 시작 추천**
